# Project 7: NASA API - Space Explorer App
Explore photos and videos from NASA's Image and Video Library.

This version uses NASA's public [Image and Video Library API](https://images.nasa.gov/docs/images.nasa.gov_api_docs.pdf). Choose a date range to find NASA media created during those dates, then select an item to see its description and credits. Unlike APOD, the library can return multiple images and videos on a date and does not require an API key.

You'll get to use your skills to build something that's actually connected to real-world data from one of the most iconic organizations in the world.

## Starter Files
- The provided files include a NASA logo, date inputs, a button, a placeholder for your gallery, and basic layout and styling to help you get started.
- The date inputs allow dates from NASA's founding in 1958 through today.
- All your custom JavaScript should go in `script.js`. That's where you'll write the code that fetches data and displays your gallery.
